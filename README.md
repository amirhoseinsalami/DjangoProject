# DjangoProject


This repository contains two Django projects:
1. Blog Post

A simple blog application where users can create, update, delete, and view posts. It includes authentication and a clean Bootstrap-based interface.<br><br>

2. Todo App

A task management application with user authentication, profile management, avatar upload, and task organization by category, priority, and status.<br><br>


Tech Stack

    Django
    PostgreSQL
    Bootstrap 5
    Python

These projects were built for learning and practicing Django web development.
